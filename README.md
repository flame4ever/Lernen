# Lernen

Kleine Lern-Apps zum Üben.

## Französisch – Unité 1: Mots de la ville

`franzoesisch/unite-1/index.html` ist ein Vokabel-Quiz mit den 16 Wörtern aus dem
*Vocabulaire thématique* von Unité 1 (la ville, le cinéma, le parc …).

Die Datei einfach im Browser öffnen, sie braucht keine Installation.

Übungen:

- **Karteikarten**: Wort ansehen, umdrehen, selbst prüfen.
- **Wort-Quiz**: aus 4 Antworten die richtige Übersetzung wählen (Französisch → Deutsch, Deutsch → Französisch oder gemischt).
- **Schreiben**: das deutsche Wort sehen und das französische Wort mit Artikel tippen. Fehlende Akzente, Artikel und der „Floh“ auf dem *où* werden erkannt.
- **Hördiktat**: das französische Wort wird vorgelesen (normal oder langsam) und muss richtig aufgeschrieben werden. Auf Wunsch wird die deutsche Bedeutung angezeigt.
- **le, la oder l'?**: den richtigen Artikel finden.

Dazu: Aussprache zum Anhören (Lautsprecher-Knopf), Lautschrift, Hinweise auf
Wörter mit anderem Geschlecht als im Deutschen, eine Runde „Nur die Fehler üben“
und ein Lernstand pro Wort (ein Wort „sitzt“ nach 3 richtigen Antworten in Folge;
gespeichert nur im eigenen Browser).

## Französisch – Unité 1: Ma ville (zweite Version zum Vergleich)

`franzoesisch/unite-1-ma-ville/index.html` übt dieselben 16 Wörter, ist aber als
Lernweg aufgebaut statt als Übungsmenü:

- **Ein Knopf „Weiter lernen“**: Die App stellt jede Runde selbst zusammen (ca. 3 Minuten).
- **6 Stufen pro Wort**: kennenlernen → Bedeutung erkennen → französisches Wort wählen →
  Artikel → Wort aus Buchstaben bauen → frei schreiben. Fehler kommen in derselben Runde wieder.
- **Wiederholung mit Abstand**: Gemeisterte Wörter werden nach 1, 3, 7 und 14 Tagen erneut abgefragt.
- **Die Stadt**: 16 Orte, die aufleuchten, je besser das Wort sitzt. le ist blau, la ist rot markiert.
- **Extra üben**: Paare finden, Fragen bauen (*Où est le cinéma ?*), Hördiktat und ein
  Vokabeltest wie in der Schule (fehlender Akzent = halber Punkt).
